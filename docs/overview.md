# 概要

最終更新: 2026-10-08

## 何のためのものか

Embedding（文章を数値ベクトルに変える処理）を使った検索の仕組みを、**手を動かして理解するための学習用プロトタイプ**。
実用の検索サービスではない。

外部の AI API（OpenAI など）を一切使わず、オープンな Embedding モデルを自分の Mac の中で実行し、
「データを事前に Embedding して保存 → 検索文をその場で Embedding → ベクトルの近さで並べる」という、
実際の AI 検索サービスと同じ流れを一通り再現している。最初に決めた要件はすべて [spec.md](spec.md) にある。

## できること

ブラウザで `http://localhost:8000` を開くと、上部のタブで3つの画面を切り替えられる。

| 画面 | 内容 |
|---|---|
| 検索 | 自然文で本を検索する（意味検索）。全冊と比べて類似度の高い上位 10 件が並び、右側に「処理の記録」（送ったリクエスト、Embedding の入力・次元・出力の先頭・かかった時間、DB から読んだ行数、類似度の式）が出る |
| 登録 | タイトルと説明を入れて本を1冊追加する。モデルに渡す文字列（`passage: …`）、生成されたベクトル、実行した SQL が出る |
| データベース | SQLite の `books` テーブルをそのまま表示する。文字の一致（`LIKE`）で絞り込める。行を選ぶと、その本のベクトル 768 個を全部見られる。削除もできる |

最初に入っているのは、実在する本 352 冊のタイトルと1文の説明（`data/books.json`）。説明文は自分で書いたもの。
日本と海外の小説、ミステリー・SF・ファンタジー、児童書・絵本、漫画、ビジネス書、教養・哲学・歴史、科学・数学、
プログラミング、AI・機械学習と、ジャンルを散らしてある（最初の5冊は spec のサンプル）。

検索の例（2026-10-08、上位3件）:
- 「魔法学校が舞台のファンタジー」→ ハリー・ポッターの3冊
- 「宇宙飛行士の話」→『宇宙兄弟』『火星の人』…
- 「プログラムを読みやすく書く方法」→『Clean Code』『リーダブルコード』…
- 「数学が得意な人が出てくるミステリー」→『数学ガール』『容疑者Xの献身』『博士の愛した数式』
  （「数学」の比重が大きく、ミステリーでない『数学ガール』がわずかに上回る）

## 使う人・公開場所

- 使うのは自分だけ。ローカル（`127.0.0.1`）でだけ動き、どこにもデプロイしていない
- ソースは GitHub の public リポジトリ `YoshitoSuzuki/local-embedding-search` に置く
  （モデル本体と DB ファイルは入れていない。各自ダウンロード・生成する）
